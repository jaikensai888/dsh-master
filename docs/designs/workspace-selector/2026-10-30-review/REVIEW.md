## 真实现状与证据

| 对象 | 真实含义 | 身份与归属依据 |
| --- | --- | --- |
| 本地 | 当前宿主提供的工作区和会话，不是 coordinator 上的一条节点记录 | 使用独立本地范围键；不能因远程节点 `my-desktop` 与本机在同一台电脑就合并 |
| 远程节点 | coordinator 登记的 DSH Host | `MasterNode.nodeId`，`nodeName` 只是显示名，`state` 和 `revoked` 决定可用性 |
| 工作区目录 | 某节点实际登记的项目目录，允许没有会话 | `MasterWorkspace.workspaceId / title / path / sessionIds`，按节点区分；不能以名称或路径当全局 ID |
| 会话 | 隶属已登记工作区，或者进入该节点“未分组”的对话 | `sessionIds` 是目录归属依据；不能根据 `cwd` 猜测归属；会话身份包含节点维度 |

## 界面布局与取舍

| 维度 | A：按节点切换（推荐） | B：按目录切换 |
| --- | --- | --- |
| 选择入口 | “工作区”文字后的小三角，点击选本地或节点 | 对照模式中同样使用小三角，菜单条目改为目录 |
| 菜单对象 | 本地 + 各远程节点；显示在线 / 离线、名称和 ID | 按本地 / 节点分组的目录；显示名称和完整路径；未分组是虚拟条目 |
| 下方内容 | 仅当前节点的目录和会话，目录可折叠；不再并列其他节点标题 | 仅当前目录的会话，不再嵌套多个目录组 |
| 适合场景 | 以机器为工作上下文，经常在同机多个项目间切换 | 项目很多，主要在单项目会话里工作 |
| 代价 | 同一节点内目录非常多时仍需滚动 | 下拉项随全部节点目录数量增长，跨项目需重复打开菜单；远程目录需先读取 |

保留宿主品牌、导航区、深色语义、行样式、在线点、底部区域。节点选择入口合并进原“工作区”标题栏，仅增加文字后的小三角，不增加卡片或单独的选择器行；目录与会话紧接标题栏显示。下方一个滚动区使用剩余高度。菜单独立滚动，并可向会话内容区域浮出，避免宽菜单挤窄 280px 侧栏。

原型为了说明浏览范围与实际会话关系，右侧标题、输入框归属提示和可定位提示也做了示意。这些是待审的交互说明，不表示已获准改动 SessionView；若批准方案，具体使用现有宿主位置或侧栏提示承载，再在实现计划中确定。

### 下拉、搜索、名称与状态

- A 菜单按节点名称 / ID 搜索；B 按节点 / 目录名称 / 路径搜索。菜单搜索与下方会话搜索互不混用，关菜单清空菜单搜索。
- 会话搜索默认收起，点击标题栏放大镜才展开；展开时自动聚焦输入框，替换标题、小三角和操作按钮，× / Escape 清除并收起。搜索期间保持当前节点范围，不额外呈现选择卡片。会话搜索范围在此原型仍限当前节点（B 对照限当前目录）；本次用户确认的是展示交互，不能据此当成已批准改变原有跨节点搜索语义，该范围变化仍待确认。
- 名称单行省略，完整名称和路径用 tooltip 展示；菜单用第二行路径和节点分组消除重名。可见选择标记代表“浏览范围”，独立的“当前会话”标记代表右侧会话所在范围。
- 在线点必须配合“在线 / 离线 / 连接中”文字。`ready` 才能视作可执行；被撤销节点在正式设计中应标“已撤销”，禁止会话操作，不能只按颜色判断。
- 离线仍可选中以查看状态，不自动跳去别的节点。无目录快照时明确“目录未加载”，不显示假的零会话。若已有最后成功快照，可保留并标记旧快照、限制在线操作；原型演示的是无快照状态。
- B 菜单按需读取远端登记目录；加载中 / 失败单独显示在所属节点分组，可重试；无法读取时不根据 `cwd` 合成目录。菜单内提供独立的“节点状态”条目，选中后可查看离线 / 未加载原因和刷新入口，不依赖方案 A。该状态条目不是虚构的工作区。原型尚未模拟真实异步请求，只呈现未加载节点状态。
- 节点很多时，在线优先、同状态保持服务端顺序，已选择节点即使离线也不丢失选择；不加入“全部节点”作为默认项，避免重新堆满侧栏。
- 当前范围刷新不清空选择与有效数据；失败显示失败状态，取消或忽略已过期响应，不能让旧请求覆盖新范围。
- 本地仍需保留添加工作区、现有可用管理动作、排序等入口；原型在“工作区”标题右侧标出放大镜、刷新、视图选项、添加工作区的位置，搜索展开时暂时隐藏这些按钮。点按管理按钮仅提示既有流程，不操作宿主。原型没有完整复刻目录重命名等宿主菜单。远程不新增本来不支持的新建目录 / 新建会话能力；原型的远程新会话入口禁用并解释原因。

### 切换与保留规则（建议）

| 动作 | 左侧 | 右侧会话 / 任务 / 草稿 / 附件 |
| --- | --- | --- |
| 切换节点或目录 | 切换浏览范围；恢复该范围搜索、滚动、折叠、overflow 状态 | 保留实际会话；不停止任务，不清草稿，不取消上传 |
| 浏览范围与右侧归属不同 | 不把无关会话强行选中 | 显示归属提示及“定位当前会话”；发送目标仍是右侧会话 |
| 点击另一条会话 | 选中该会话 | 使用既有会话切换行为；附件清理沿用既有契约，本提案不承诺跨会话保留上传 |
| 点击“定位当前会话” | 切回所属范围；搜索若隐藏当前会话则清除；展开所属目录和 overflow 并滚到该行 | 右侧内容及草稿保持；这是显式定位操作对搜索 / 展开状态的例外 |
| 节点离线或目录不可用 | 保留已选范围，提示原因与刷新 | 对真实属于该离线节点的会话沿用既有不可发送状态；不自动换会话 |
| 重新打开应用 | 恢复上次有效浏览范围；不存在时明确回退本地并提示 | 不在本任务顺手解决现有面板选择不持久化问题 |

状态建议按 `{kind:local}` / `{kind:remote,nodeId}`，B 再加 `workspaceId` 区分；本地与远程状态严格分开，未分组使用专用标记而非目录名称。保留现有 v5 排序和展开设置。原型状态只保留在页面内存，重置和刷新会清空，不是正式持久化实现。
